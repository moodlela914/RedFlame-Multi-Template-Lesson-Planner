# 資訊議題跨域範本規則

格式來源 templates/資訊議題跨域教案(空白).docx；內容格式參考 examples/multi_template/cross-domain.json。公開版不含使用者提供的完整教案、學生作品或真實成效。

範本為直式 A4（21×29.7 cm），上下邊界以原檔為準，左右各 1.5 cm。原字型標楷體，正文主要 14pt，標題有不同尺寸。主表 24 列、9 個底層網格欄，第一欄極窄，其他欄有水平及垂直合併，不能將九個網格欄當作九個可見資料欄。

表格前：主題、設計者、設計理念（動機、學習歷程、素養說明）、主題架構。

表格中（列與欄為程式 0 起算）：

| 區塊 | 列 | 內容欄網格起點 |
|---|---|---|
| 主題／基本資料 | 0–3 | 3、6 |
| 學科、數位先備經驗 | 5–6 | 3 |
| 總綱面向、項目 | 7 | 3、6 |
| 領域與議題的三組對應 | 8–10 | 3、6 |
| 學習目標、評量策略、教學資源 | 11–13 | 3 |
| 活動標題與表頭 | 14–15 | 保留 |
| 可變活動列 | 16 起 | 1 活動、4 時間、5 評量、7 策略、8 備註 |
| 省思標題、內容 | 活動列之後 | 1 |

流程一節一列，原六列替換為 N 列，主表列數 18 + N。評量規準在附錄新增表格，數量與規準形式依課程而定，不套用原指引格式的固定五表檢核。

公開版已清除空白檔殘留的主題、設計者姓名及文件作者資訊；填表時主題與設計者在段落及主表一併填入。簽名、審核勾選與專家簽名保持空白。示範中的學生作品、成效與教學回饋只作參考，不能挪用為新課程事實。

驗收：主表合併結構、方向與必要欄位；N 節完整且時間正確；省思與附錄齊備；目標與評量對應；課綱分類與代碼另行查核。實際分頁需在 Word 或渲染圖片逐頁檢視，結構檢核不能取代視覺驗收。
